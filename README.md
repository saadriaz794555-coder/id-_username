# Student Campus Dashboard

A Flutter UI assignment for a student digital ID card and campus dashboard.

## Run

1. Install Flutter SDK.
2. Open the project folder in VS Code or Terminal.
3. Run:

```bash
flutter pub get
flutter run
```

## Features

- AppBar with title, drawer menu, and search action
- Student ID card card layout with profile image and online indicator
- Student details aligned with rows and spacing
- Dynamic enrolled courses list using ListView.builder
- Notes input field and submit button
